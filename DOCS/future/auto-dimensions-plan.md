# План: модуль «Проставить размеры» (план и разрезы)

## Сценарий
1. Открыт активный план или разрез → кнопка «Проставить размеры» на панели «Виды сборок».
2. Если активный вид не план/разрез — вежливый отказ.
3. Собираются все видимые модельные элементы вида (коллектор по виду, фильтры учтены).
4. Повторный запуск: сначала удаляются размеры, созданные ранее плагином на этом виде
   (метка в параметре «Комментарии» = «Assembling Manager»), затем ставятся свежие.

## Какие размеры и куда
Направления берутся из системы вида (RightDirection/UpDirection — работает на повёрнутых планах):

| Вид | Цепочка | Габарит |
|---|---|---|
| План | по X — снизу, по Y — справа | под цепочкой / правее цепочки |
| Разрез | горизонтальная — снизу | длина — ниже цепочки, высота — справа |

Отступы от габарита геометрии: цепочка 500 мм, общий габарит 1500 мм.
Стиль размера — тип по умолчанию проекта.

## Техника
- Для каждого элемента геометрия в контексте вида (Fine); берутся только плоские грани,
  перпендикулярные направлению размера и видимые с ребра (не параллельные листу).
- Цепочка = позиции граней, отсортированные и склеенные с допуском 0,5 мм →
  `NewDimension` со списком ссылок (N ссылок = N-1 сегмент).
- Габарит = две крайние грани.
- Линии размеров строятся в плоскости вида: `view.Origin + Right*x + Up*y`.
- Один `Transaction` с `FailurePreprocessor`; откат при ошибке; Ctrl+Z отменяет всё разом.
- Созданным размерам проставляется метка «Assembling Manager» в «Комментариях».

## Привязка трасс к осям
- Оси вида (`Grid`) делятся на вертикальные/горизонтальные по направлению линии; ссылка на ось —
  `new Reference(grid)` (у базовых элементов нет свойства Reference).
- Сегменты сети — `MEPCurve` (трубы/воздуховоды/лотки) по осевой линии: экранно-вертикальные
  привязываются по X к ближайшей вертикальной оси, экранно-горизонтальные по Y к горизонтальной,
  стояки — по обеим координатам.
- Соосные сегменты склеиваются с допуском 1 мм — одна привязка на трассу.
- Ссылка на трубу — самая большая цилиндрическая грань (Revit измеряет до оси трубы).
  Если привязки массово не создадутся — запасной план: ссылки на торцы.
- Линия привязки ставится за дальним концом сегмента, отступ 250 мм.
- Метятся тем же маркером «Assembling Manager» → повторный запуск обновляет.
- Чтение геометрии: `Options.ComputeReferences = true` — обязательно, иначе у граней нет ссылок
  (причина «нулевого» первого запуска).

## Ограничения
- Элементы без плоских перпендикулярных граней (отводы, криволинейные детали) пропускаются
  со счётчиком в сводке.
- Оси, уровни, аннотации, связи не размерятся.
- Модуль задуман для видов сборок: на обычном плане размерится всё видимое.

## Чек-лист ручной проверки (агент не может запустить Revit)
1. План сборки → цепочка снизу и справа, габариты под ними; на аннотациях ничего не появилось.
2. Разрез → горизонтальная цепочка снизу, габарит длины под ней, высота справа.
3. Повторный запуск → старые размеры плагина заменены, дублей нет.
4. Запуск на 3D-виде/листе → вежливый отказ.
5. Ctrl+Z → всё отменяется одним шагом.
6. Криволинейные элементы → пропущены, счётчик в сводке.
