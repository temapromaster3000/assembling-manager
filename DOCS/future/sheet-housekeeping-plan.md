# План (будущее): модуль «Порядок листов»

Отдельный модуль для наведения порядка в листах, вынесенный из «Разместить на листах»
(там листы больше не анализируются — только карта размещения видов).

## Задачи модуля
1. Удаление пустых листов (лист существует, но на нём нет ни одного вида сборки) —
   кандидаты: листы без вьюпортов/инстансов либо с видами вне групп.
2. Естественная сортировка листов — РЕАЛИЗОВАНА в модуле
   «Разместить на листах» (`NaturalStringComparer`, `BuildSheetTree`, `GetSheets`).
3. Прочее по мере необходимости (переименование листов «(не размещенное)» и т.п.).

## Контекст
- Сортировка листов применяется в `SheetService.GetSheets` и
  `BrowserGroupService.BuildSheetTree` (сейчас `StringComparer.OrdinalIgnoreCase`).
- Удаление пустых листов не отменяет новую логику размещения:
  модуль «Разместить на листах» продолжает работать только по карте.

## Чек-лист ручной проверки (когда дойдут руки)
1. Нумерация листов в дереве: `…01, …02, …, …10` (числовой порядок).
2. Пустые листы без видов — удалены (после подтверждения пользователем через список).
3. Листы «(не размещенное)» и «(начало)»/«(окончание)» — не тронуты.
