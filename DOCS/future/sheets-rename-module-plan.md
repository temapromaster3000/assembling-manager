# План (будущее): отдельный модуль «Переименовать листы»

## Идея
Модуль «Переименовать сборки» переименовывает ТОЛЬКО виды/спецификации.
Переименование листов, на которые размещены виды сборки, выносится в отдельный модуль
(кнопка на панели «Листы»), так как:
- лист может содержать виды нескольких сборок — такие листы исключаются из обработки;
- у листа может быть собственное имя, не совпадающее ни с одним из имён сборки.

## Определение принадлежности листа
- Лист belongs to «переименованная сборка», если на нём размещены виды ТОЛЬКО этой сборки:
  базовые имена размещённых видов (после снятия суффиксов `_Вид спереди`, `_Спецификация` и т.д.)
  образуют ровно одно имя, и это имя — новое имя переименованной сборки.
- Строгое сравнение (без нормализации ` (2)`) — по решению пользователя.
  Если при проверке выяснится, что виды имеют копийные суффиксы ` (2)` — вернуться к вопросу.
- Лист с видами нескольких сборок — пропуск с логом INFO и счётчиком в отчёте.
- Лист без наших видов / только с видами чужих объектов — пропуск.

## Что переименовывать у листа
- Элементное имя `ViewSheet.Name` = новое имя сборки (с подбором свободного `(2)` и т.д.).
- Параметр «Имя листа» (SHEET_NAME) — только если он заполнен старым именем сборки
  (ручную подпись проектировщика не трогаем).

## Диагностика прошлой проверки (почему лист не переименовался)
Требуется выяснить на реальной модели:
1. Состав видов на «проблемном» листе (какие имена видов лежат, базовые имена после суффиксов).
2. Построить карту состава листов с логированием; причины пропуска писать в INFO:
   «лист NN пропущен: объекты: A, B, C».

## Производительность
- Двухфазный проход: сначала переименование видов (модуль «Переименовать сборки»),
  затем ОДИН проход по листам с картой «новое имя → старое имя» (не «сборки × листы»).

## Признаки успеха (чек-лист ручной проверки)
1. Лист только с видами переименованной сборки — переименован (имя + параметр SHEET_NAME,
   если был = старим именем), в отчёте «Переименовано листов: m».
2. Лист с видами нескольких сборок — имя не тронуто, в отчёте «Пропущено листов: k».
3. Повторный запуск без изменений — 0 переименований.
4. Ctrl+Z — откат одним шагом.

## Отчёт модуля
- «Переименовано листов: m», «Пропущено листов (несколько сборок): k»,
  список «Старое имя → Новое имя» для листов.
