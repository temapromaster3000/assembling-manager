# Модуль «Проверка отметок»

## Цель

Новый модуль в группе ленты **«Оформление»**: выбрать комплект листов (группу из диспетчера проекта) и получить список листов, ни на одном размещённом виде которых нет высотной отметки.

## Решения

- Модуль только читает модель — транзакции не нужны.
- Окно немодальное: Revit остаётся доступным, окно плагина не блокирует работу.
- Комплект — группа листов из диспетчера проекта (как в модуле «Сортировка листов»), обход рекурсивный.
- Отметка — системная аннотация **«Высотная отметка»** (`BuiltInCategory.OST_SpotElevations`).
- Лист принят, если хотя бы на одном его виде есть отметка, не скрытая категорией и не скрытая индивидуально.
- Листы без размещённых видов показываются в результате с количеством видов `0`.
- Переход к листу — `UIDocument.RequestViewChange`: лист открывается вкладкой Revit, окно плагина остаётся открытым.

## Ручная проверка

- [ ] Кнопка «Проверка отметок» появилась в группе «Оформление», иконки 16/32 читаются.
- [ ] Лист с отметкой хотя бы на одном виде не попадает в таблицу.
- [ ] Лист без отметок попадает в таблицу.
- [ ] Лист без размещённых видов попадает в таблицу с «Видов на листе = 0».
- [ ] Вложенные группы комплекта проверяются.
- [ ] Отметка в зависимом виде (dependent view) на листе считается; лист без отметок в зависимом виде попадает в отчёт.
- [ ] После добавления отметки повторная проверка убирает лист из списка.
- [ ] ПКМ по строке → «Перейти к листу»: лист открывается в Revit, окно плагина остаётся открытым.
- [ ] Работа с Revit при открытом окне плагина не блокируется.
- [ ] При закрытии документа/Revit окно закрывается без ошибок.
- [ ] Повторный запуск команды активирует уже открытое окно, второе не создаётся.
- [ ] Проверка в файл-хранилище работает, элементы других пользователей не затрагиваются.
