# План: модуль «Ближайшие оси» (панель «Оформление»)

Статус: **в работе**. Переместить в `docs/realized/` после пуша коммитов фичи на GitHub.

## Задача

По регламенту на видах, где видна только одна проектная ось, нужно показать ближайшие оси —
хотя бы стрелочкой с именем следующей оси. Для этого используется аннотационное семейство
**«Ближайшие оси - марка»**, которое ставится в центр кружка оси и рисует стрелки в стороны
с именами соседних осей.

Модуль: пользователь выбирает сборки → плагин находит их виды (план и разрезы) → на видах,
где видна ровно одна ось данной ориентации, ставит маркеры и заполняет имена соседей.

## Утверждённые решения

- **Выбор видов**: окно со списком сборок: поиск по сборке, колонки «№» и «Взять» (галочка).
  Мультивыбор: клик и Ctrl+клик переключают строку, Shift+клик применяет состояние якорной
  галочки ко всему диапазону (включая строки, скрытые поиском). «Выбрать всё/Снять всё»
  и счётчик выбранных сохранены. Обрабатываются виды сборок:
  план (`имя сборки`) и разрезы (`_Вид спереди`, `_Вид сзади`, `_Вид справа`, `_Вид слева`). 3D не трогаем.
- **Отчёт**: компактное окно «Обработка завершена»: создано маркеров, пропущено видов,
  счётчик предупреждений (подробности — в логе), время работы. Детальное размещение
  и список предупреждений — только в логе плагина.
- **Рабочие наборы осей**: в списке окна — только пользовательские наборы
  (`WorksetKind.UserWorkset`, включая два стартовых набора Revit: «Общие уровни и оси», «Рабочие наборы1»).
  Служебные наборы (семейства, виды, стандарты) не показываются. Оси выбранного набора
  обрабатываются полностью (кандидаты и соседи); оси других наборов игнорируются.
  Хранение по имени; если набор не найден — откат на «Все» с предупреждением в отчёте.
- **Разрезы**: ось на разрезе видна вертикальной линией; разрез может быть перпендикулярен
  как цифровым, так и буквенным осям — семейство осей не важно, все оси обрабатываются одинаково.
- **Критерий «ось видна»**: нарисованная в виде линия оси (см. ниже) пересекает область обрезки вида.
  Скрытие оси в виде, фильтры, шаблоны учитываются через `FilteredElementCollector(doc, view.Id)`.
- **Точка вставки маркера — «системное» положение кружка в виде** (одна формула, без разбора случаев):
  1. Берём нарисованную в данном виде линию оси через `DatumPlane.GetCurvesInView`
     (учитывает 2D-протяжённости конца, оттянутого пользователем; запасной вариант — `Grid.Curve`).
  2. Определяем концы, где включён кружок, через `DatumPlane.IsBubbleVisibleInView(End0/End1, view)`.
  3. Маркер ставится на **каждом** конце с включённым кружком: один кружок — один маркер,
     два — два (с одинаковыми именами соседей). Ни одного — маркеры не ставятся.
  4. Если конец оси **оттянут пользователем в этом виде** (тип протяжённости ViewSpecific) →
     маркер на оттянутом конце, **без зажима**.
  5. Если конец не оттянут и **обрезка вида включена** (`CropBoxActive`) → конец зажимается
     в границы аннотационной обрезки вида (системная граница, по умолчанию 25,4 мм на листе;
     `ViewCropRegionShapeManager`, офсеты × масштаб вида).
  6. Если **обрезка вида выключена** → зажима нет, маркер на конце линии + R; геометрическая
     проверка видимости по границе не выполняется (Revit хранит устаревшую границу в CropBox).
     Видимы все оси модели, поэтому правило «ровно одна ось» на таких видах обычно не срабатывает.
  7. Точка = итоговый конец + R наружу (в экранных координатах вида), R — радиус кружка
     в пересчёте на лист (мм × масштаб вида).
- **Настройки пользователя** (только две):
  - радиус кружка оси, мм (по умолчанию 5);
  - рабочий набор осей: «Все рабочие наборы» или конкретный набор (оси-исключения в другом
    наборе полностью игнорируются — и как кандидаты, и как соседи). Поле заблокировано,
    если модель не в совместной работе. Хранение по имени; если набор не найден —
    откат на «Все» с предупреждением в отчёте.
- **Соседи**: геометрически по всей сетке модели (с фильтром рабочего набора): параллельные
  оси сортируются по поперечной координате в экранных координатах вида; сосед — предыдущий/следующий.
  Имя соседа — `Grid.Name`. Крайняя ось → один сосед; промежуточная → оба.
- **Повторный запуск**: маркеры, стоящие на линии этой оси (по перпендикулярному расстоянию),
  удаляются и создаются заново с актуальными именами.
- **Семейство**: если «Ближайшие оси - марка» не загружено — предупреждение, отмена.
- **Параметры семейства**: видимость `Верхняя ось`, `Нижняя ось`, `Левая ось`, `Правая ось`;
  имена соседей `Имя оси сверху`, `Имя оси снизу`, `Имя оси слева`, `Имя оси справа`.
- Направления вычисляются в экранных координатах вида (работают для повёрнутых планов
  и перевёрнутых разрезов). Косые оси (более 20° от горизонталей/вертикалей экрана) игнорируются.
- Виды, где осей данной ориентации 2 и больше — не трогаются (запись только в лог,
  в счётчик предупреждений отчёта не попадают — это штатный пропуск).
- **Предупреждения в отчёте** — только реальные проблемы: косая/непрямая ось, у оси нет соседей,
  не найден параметр в семействе, не найден рабочий набор. Штатные пропуски — только в логе.
- **Пресеты** хранятся в документе (ExtensibleStorage, схема v2): радиус хранится строкой
  (поле double требует единиц измерения — причина бага «Units are required»).

## Диагностика

- DEBUG-лог по каждой оси: проекции, проверки видимости, состояния кружков, вычисленная точка.
- После создания маркеров — readback их фактических позиций в координатах вида.
- Логи: `%APPDATA%\Autodesk\Revit\Addins\AssemblingManager\Logs`.

## Ограничения / риски (проверить в Revit)

1. Маркеры за обрезкой вида должны быть видны на листе (зависит от «Аннотационной обрезки»).
2. `GetCurvesInView` может вести себя нестандартно на некоторых типах осей (дуги, составные) —
   запасной вариант `Grid.Curve`; кривые (не прямые) оси пропускаются с записью в лог.
3. Смешанные типы протяжённостей концов (End0 3D + End1 2D) — запасной цепочкой вариантов.

## Чек-лист ручной проверки (Revit)

- [ ] План сборки: одна буквенная ось, крайняя → маркер на «системном» расстоянии за границей
      вида (аннотационная обрезка), имя только в одну сторону.
- [ ] Вид с выключенной обрезкой (видны многие оси) → пропускается, маркеров нет
      (раньше плагин ошибочно использовал устаревшую границу CropBox).
- [ ] Ось, чей конец чуть за границей вида (как «Д»/«4» на скринах) → маркер ровно на кружке,
      на системном отдалении, а не у границы и не в реальном конце оси.
- [ ] Оттянутая в виде ось → маркер на оттянутом конце, без зажима.
- [ ] План сборки: промежуточная ось → имена двух соседей (например, у Б — А и В; у 8 — 7 и 9).
- [ ] Ось с двумя включёнными кружками → два маркера.
- [ ] Ось с перетаснутым в виде концом (2D-протяжённость) → маркер на перетаснутом конце.
- [ ] Разрезы сборки («Вид спереди/сзади/справа/слева») → маркер снизу, имена слева/справа;
      работает и для разрезов поперёк буквенных осей.
- [ ] Маркеры за обрезкой вида видны на листе (viewport).
- [ ] Оси-исключения из другого рабочего набора игнорируются (у 5 сосед — 6, не 5а);
      «Все рабочие наборы» — прежнее поведение.
- [ ] В списке рабочих наборов только пользовательские наборы (+ «Общие уровни и оси»),
      без служебных наборов Revit.
- [ ] Вид с 2+ осями одной ориентации — не изменён.
- [ ] Повторный запуск — маркеры обновлены, дублей нет; переименованная сетка → имена обновились.
- [ ] Семейство не загружено → предупреждение; модель без сборок → сообщение.
- [ ] Радиус и рабочий набор запоминаются между запусками (пресеты после обновления сбрасываются один раз).
- [ ] Поиск в окне фильтрует (подсказка пропадает при вводе, кнопка «✕» появляется),
      № не пересчитывается при поиске.
- [ ] Мультивыбор: клик/Ctrl+клик переключают строку, Shift+клик отмечает диапазон
      по якорной галочке (включая скрытые поиском строки).
- [ ] Отчёт компактный: создано/пропущено/предупреждения/время; детализация — в логе.
- [ ] Прогнать в основной версии Revit; при проблемах прислать лог из папки Logs.
