# План: модуль «Разместить виды на листах»

## Цель
Новая кнопка на панели «Виды сборок»: копирует выбранный лист-образец для каждого «объекта» из выбранной группы диспетчера видов и размещает виды объекта вокруг копии листа.

## Сценарий работы
1. Кнопка «Разместить на листах» → диалог:
   - дерево групп видов (по активной схеме организации браузера: «02_Оформленные виды» → «ТХ»), выбор одной группы целиком;
   - дерево листов (по организации браузера листов: комплект → листы), выбор одного листа-образца;
   - счётчик «Объектов: N → будет создано листов: N».
2. Конфликты: если для объекта уже существует лист с тем же именем — диалог `SheetConflictDialog`
   (галочка «Заменить» по умолчанию выключена). Отмена диалога отменяет всю операцию.
3. Виды берутся только из выбранной группы и группируются по базовому имени
   (отрезаются суффиксы `_План`, `_Вид спереди`, `_Вид сзади`, `_Вид справа`, `_Вид слева`, `_3D`, `_Спецификация`).
   Базовое имя = «объект».
4. Для каждого объекта:
   - нет конфликтов → копия листа-образца: штамп как у образца, имя листа = имя объекта,
     номер продолжает нумерацию образца (занятые пропускаются; без цифр на конце — суффикс «-01»);
     с образца копируются параметры группировки листов (лист попадает в ту же группу диспетчера);
   - конфликт + «Заменить» → существующий лист обновляется (см. семантику замены), новый не создаётся;
   - конфликт без «Заменить» → объект полностью пропускается, дубликат не создаётся.
5. Раскладка видов вокруг листа (2 прохода: создание → замер фактических габаритов → точный сдвиг;
   отступ от края листа 25 мм, между видами в ряду/столбике 50 мм):
   - сверху в ряд — планы; справа столбиком — 3D; снизу в ряд — спецификации;
     слева столбиком — разрезы (спереди → сзади → справа → слева).
6. Сводка: создано / обновлено листов, пропущено объектов, предупреждения.

## Семантика замены (без потери наработок проектировщика)
- Номер, имя листа, штамп — сохраняются.
- Аннотации (тексты, размеры, линии), чужие виды — сохраняются всегда.
- Видпорт вида объекта на целевом листе — сохраняется как есть (вместе с ручной позицией).
- Актуальный вид, лежащий на листе-дубликате, — переносится на целевой лист с сохранением позиции
  (видпорт с дубликата снимается).
- Видпорты с шаблонным именем объекта, чей вид не входит в текущий набор (защитная чистка),
  — удаляются. Из-за уникальности имён видов в Revit такой случай практически не встречается.
- Несколько одноимённых листов: обновляется первый по номеру, остальные чистятся от шаблонных видпортов.

## Технические заметки
- **Важно:** у `ViewSheet` чтение `sheet.Name` возвращает строку в формате «Номер - Имя» (как в
  диспетчере), а запись принимает чистое имя. Чистое «Имя листа» читать только через параметр
  `BuiltInParameter.SHEET_NAME` — хелпер `SheetService.GetSheetName(sheet)`. Сравнение имён листов —
  через этот хелпер, с `Trim` и без учёта регистра.
- Дерево групп: `BrowserOrganization.GetFolderItems(view.Id)` возвращает путь вместе с последним
  автоматическим уровнем (тип вида: «Планы этажей», «Разрезы», «3D виды») — этот уровень отбрасывается,
  иначе группу («ТХ») нельзя выбрать целиком. Одиночный уровень остаётся только если он параметрический.
- Параметры группировки листов: `GetCurrentBrowserOrganizationForSheets().GetFolderItems(master.Id)`
  → копирование значений этих параметров с образца на новые листы (по StorageType).
- Позиционирование: создание видпорта → `doc.Regenerate()` → замер `get_BoundingBox(sheet)` /
  `Viewport.GetBoxOutline()` → `ElementTransformUtils.MoveElement`.
- `ViewSheet.Outline` имеет тип `BoundingBoxUV`; контур видпорта — `Viewport.GetBoxOutline()` (XYZ).
- Вид, уже размещённый на любом листе, повторно не размещается (пропуск с предупреждением).

## Чек-лист ручной проверки (агент не может запустить Revit)
1. Собрать `build-and-deploy.bat`, открыть модель с оформленными видами в группе и ≥1 листом.
2. Дерево групп совпадает с диспетчером; «ТХ» выбирается целиком (без деления на планы/разрезы/3D);
   счётчик объектов верен.
2a. Дерево листов совпадает с диспетчером листов (группы комплектов → листы); выбирается только
   конкретный лист (узел «Номер — Имя»), группы-комплекты не выбираются.
3. Создались листы: номера продолжились, имена = имена объектов, штамп как у образца,
   листы лежат в той же группе диспетчера, что и образец (не в «???»).
4. Раскладка: планы сверху в ряд, 3D справа, спецификации снизу, разрезы слева столбиком.
5. Повторный запуск по той же группе: появляется диалог конфликтов, галочки по умолчанию сняты;
   после выполнения без замен ничего не изменилось, дубликаты не создаются.
6. С включённой заменой: аннотации и актуальные видпорты уцелели, недостающие виды добавлены.
7. Вид, уже лежащий на чужом листе → пропущен, предупреждение в сводке.
8. Отмена любого диалога → модель не изменилась.
