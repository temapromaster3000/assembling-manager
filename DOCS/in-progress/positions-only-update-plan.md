# Опция «Только обновить позиции» в модуле «Проставить позиции»

## Проблема

Модуль «Проставить позиции» всегда проходит два этапа: запись позиций в экспликации (этап 1) и расстановка марок на видах (этап 2, окно выбора марок). Иногда нужно только обновить позиции в экспликациях, не трогая уже расставленные марки — сейчас для этого приходится пролистывать второе окно, и его отмена отменяет весь запуск.

## Цель

- Галочка **«Только обновить позиции (марки не трогать)»** в первом окне модуля, рядом с «Объединить спецификации».
- По умолчанию **выключена** — стандартный сценарий с двумя этапами не меняется.
- Включена → этап 2 пропускается целиком: окно марок не открывается, категории и марки не собираются (запуск быстрее), расставленные марки остаются как есть, пресет марок не перезаписывается.
- В отчёте — пометка «Марки: пропущены (режим «только позиции»)».
- В пресет проекта опция **не сохраняется** (как «Объединить спецификации»).

## Реализация

1. **`Views/AssignPositionsDialog.xaml`** — новый `CheckBox` `OnlyPositionsCheckBox` (`IsChecked="False"`) в StackPanel с `MergeSchedulesCheckBox`; ToolTip поясняет режим и неперсистентность.
2. **`Views/AssignPositionsDialog.xaml.cs`** — свойство `public bool OnlyPositions` по образцу `MergeSchedules`.
3. **`Commands/AssignAssemblyPositionsCommand.cs`**:
   - после чтения окна 1 — `bool onlyPositions = dialog.OnlyPositions;` + лог;
   - блок сбора категорий и показа `AssignTagsDialog` обёрнут в `if (!onlyPositions) { ... }`; декларации с дефолтами (`selectedTagSymbols`, `minOffsetMm`, `zoneHeightMm`, `textBelowShelf`, `tagService`) остаются снаружи — словарь марок пуст, и существующие гейты (`selectedTagSymbols.Count > 0`, `tagChoices != null && tagChoices.Count > 0`) сами пропускают `PrepareTagDimensions` и `PlaceTags`;
   - `List<Category> elementCategories` перенесена внутрь блока (вне режима не используется);
   - отчёт: при включённом режиме ветка `if (onlyPositions)` добавляет пометку, иначе прежний блок `tagResult`.
4. Транзакции/TransactionGroup, `TagService`, `AssignTagsDialog`, `PositionPresetStorage`, `TagPresetStorage` — без изменений.

## Контрольный список ручной проверки

1. Запустить модуль: галочка по умолчанию **снята**; оба окна открываются как раньше; марки ставятся — поведение не изменилось.
2. Включить галочку, нажать «Выполнить»: второе окно **не открывается**; позиции в спецификациях обновляются; расставленные марки остаются на местах без изменений.
3. В отчёте видна пометка «Марки: пропущены (режим «только позиции»)».
4. Перезапустить модуль: галочка снова снята (не персистится); пресет ключевых слов сохраняется как обычно; сохранённый пресет марок (окно 2) не сбросился — при следующем обычном запуске прежние выборы на месте.
5. «Отмена» в окне 1 при включённой галочке — модель не меняется.
6. Смешанный сценарий: с галочкой → без галочки: окно 2 открылось, пресет марок подставился.
