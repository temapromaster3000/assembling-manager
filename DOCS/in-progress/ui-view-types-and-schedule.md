# План: переработка UI — выбор типов видов и блок спецификации

## Цель
Улучшить окно плагина:
- позволить пользователю выбирать типоразмер вида для планов, разрезов и 3D видов;
- перенести настройки спецификации в логичный блок;
- сделать шаблоны видов активными только при включённых соответствующих видах.

## Размеры окна и рамок
- Ширина окна увеличивается, чтобы вместить две колонки в правой верхней рамке.
- Высоты рамок остаются прежними:
  - верхний ряд: 150;
  - нижний ряд: 170.
- Отступы внутри правых рамок подгоняются под отступы в левых, чтобы элементы были на одной горизонтали.

## Рамка «Виды» (верхняя правая, высота 150)
- Убирается галочка «Спецификация».
- Заголовок рамки разделён на две части:
  - слева — «Виды»;
  - справа — «Типы видов».
- Внутри рамки две колонки с вертикальной разделительной линией:
  - левая — галочки: План, Разрезы (+ кнопка настроек), 3D вид;
  - правая — выпадающие списки типов видов напротив каждого пункта.
- Выпадающий список типа активен, только когда включена соответствующая галочка.
- По умолчанию в каждом списке выбран первый типоразмер из проекта.

## Рамка «Спецификация» (нижняя правая, высота 170)
- Верхняя строка: «Спецификация для каждой сборки:».
- Ниже — радио-кнопки «Да» / «Нет» в одну строку (группа, по умолчанию «Нет»).
- Ещё ниже — выпадающие списки:
  - Мастер-спецификация;
  - Шаблон вида.
- При «Нет» списки неактивны и полутоновые.
- При «Да» списки активны.

## Рамка «Шаблоны видов» (нижняя левая)
- Выпадающие списки шаблонов активны только при включённых соответствующих видах:
  - План — если включён «План»;
  - Разрезы — если включён хотя бы один разрез;
  - 3D вид — если включён «3D вид».

## Изменения в коде

### Модель
- В `ViewCreationOptions` добавить:
  - `PlanViewFamilyTypeId`;
  - `SectionViewFamilyTypeId`;
  - `View3DViewFamilyTypeId`.

### Сервисы
- Создать `ViewFamilyTypeService` с методами:
  - `GetPlanTypes(Document)`;
  - `GetSectionTypes(Document)`;
  - `GetView3DTypes(Document)`.
- Обновить `ViewService.GetViewFamilyTypeId`, чтобы принимать выбранный тип.
- Для дублируемых планов и 3D видов менять тип на выбранный через `ChangeTypeId`.
- В `OrchestratorService` передавать выбранные типы видов из `ViewCreationOptions` в `ViewService`.

### UI
- Переработать `MainWindow.xaml`:
  - перенести галочку спецификации в блок спецификации;
  - добавить радио «Да/Нет»;
  - разделить рамку «Виды» на две колонки;
  - добавить выпадающие списки типов видов;
  - привязать `IsEnabled` шаблонов и типов видов к состоянию галочек.
- Обновить `MainWindow.xaml.cs`:
  - инициализация списков типов видов;
  - обработка радио спецификации;
  - обновление счётчика;
  - формирование `Options`.

- [ ] Списки типов активны только при включённых видах.

- [ ] Созданные виды получают выбранный типоразмер.
