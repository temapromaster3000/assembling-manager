# Модуль «Добавить существующее»

## Проблема

Элементы проекта разделены по стадиям: существующее и новое. Сборки (`AssemblyInstance`) не могут объединять
элементы разных стадий, поэтому сборками охвачено только «новое». Существующим элементам приходится вручную
вписывать значение параметра (имя сборки), чтобы они попадали под фильтр видов сборки. У существующих
элементов бывают общие вложенные семейства, которым значение нужно вписать отдельно — это трудоёмко.

## Решение

Новый модуль в группе «Сборки»: кнопка **«Добавить существующее»**.

1. Пользователь жмёт кнопку → выбирает элементы (рамка/Ctrl, «Готово») через `PickObjects`.
2. Открывается окно: выбор параметра (радиокнопки `AssemblyParameter` / `ADSK_Группирование` — всегда
   спрашиваем; статус наличия показан) и выбор одной сборки из всех сборок проекта (поиск, natural-сортировка).
3. Перед записью: если у части элементов параметр уже заполнен — подтверждение перезаписи.
4. Одна транзакция:
   - до-привязка недостающих категорий к параметру (`ParameterService.AddMissingCategories`) + `Regenerate`;
   - запись имени выбранной сборки в параметр всем выбранным элементам и их вложенным семействам
     (рекурсия по `GetSubComponentIds`);
   - добавление недостающих категорий в фильтр выбранной сборки
     (`FilterService.EnsureAssemblyFilter` с объединением категорий; пересоздание фильтра =
     предупреждение в сводке для workshared-моделей).
5. Сводка через MessageBox: сколько записано (в т.ч. вложенных), какие категории добавлены, что с фильтром.

## Принятые решения

- Категории добавляются **только в фильтр выбранной сборки** (по выбору пользователя).
- Параметр спрашивается всегда; `AssemblyParameter` при отсутствии создаётся автоматически (как в основном
  модуле), `ADSK_Группирование` при отсутствии — выбор блокируется.
- Перезапись существующих значений — с подтверждением.

## Контрольный список ручной проверки (в Revit)

- [ ] Кнопка «Добавить существующее» есть в группе «Сборки», окно открывается.
- [ ] Выбор элементов рамкой и через Ctrl, «Готово» — окно выбора открывается.
- [ ] Существующий элемент с вложенным общим семейством: значение пишется и родителю, и вложенному.
- [ ] Элемент с новой категорией: категория добавлена в привязку параметра и в фильтр выбранной сборки,
      элемент виден на видах этой сборки.
- [ ] Предупреждение о перезаписи появляется, если у элемента параметр уже заполнен; при отказе ничего не меняется.
- [ ] Отмена на любом шаге не меняет модель.
- [ ] Сводка после выполнения показывает корректные числа.
- [ ] Проверено в Revit 2021 и Revit 2025 (сборки Debug.R21 / Debug.R25).
