# Автоматическая привязка недостающих категорий

## Статус

Implemented.

## Цель

Упростить UI выбора параметра: вместо списка непривязанных категорий показывать только количества. Недостающие категории при использовании `ADSK_Группирование` добавляются автоматически после нажатия «Сформировать».

## Поведение

- В рамке «Параметр для фильтра» после двух радиокнопок две строки статуса.
- Обе строки показываются всегда.
- Цвет текста зависит от значения:
  - если `N == 0` — чёрный;
  - если `N > 0` — оранжевый.
- При выборе `ADSK_Группирование`:
  - Если параметр не найден:
    - первая строка: «Параметр не найден» красным;
    - вторая строка пустая;
    - кнопка «Сформировать» заблокирована.
  - Если параметр привязан только к типам (`TypeBinding`):
    - первая строка: «Параметр создан по типу» красным;
    - вторая строка пустая;
    - кнопка «Сформировать» заблокирована.
  - Иначе:
    - первая строка: `Будет привязано категорий: N`;
    - вторая строка: `Будет перезаписано значений: N`;
    - кнопка активна.
- При выборе «Создать новый общий параметр»:
  - первая строка: `Будет создан общий параметр с именем 'AssemblyParameter'` **оранжевым**;
  - вторая строка пустая;
  - кнопка активна.

## Изменения в коде

### 1. `MainWindow.xaml`

- Убраны `TextBlockMissingCategoriesHeader` и `ItemsControlMissingCategories`.
- В `ScrollViewer` оставлены два `TextBlock`: `TextBlockLine1` и `TextBlockLine2`.

### 2. `MainWindow.xaml.cs`

- Добавлен метод `SetStatusLine(TextBlock, string, int)` для установки текста и цвета.
- Обновлён `ValidateGroupingParameter`:
  - проверка `IsValid` → красное сообщение и блокировка;
  - если `IsTypeBinding` — сообщение «Параметр создан по типу»;
  - иначе если не найден — «Параметр не найден»;
  - иначе показываются две строки с количествами.
- Обновлён `ShowCreateNewParameterInfo`.
- Обновлён `ClearParameterStatus`.

### 3. `ParameterValidationResult`

- Добавлено свойство `IsTypeBinding` для различия между отсутствием параметра и привязкой по типам.

### 4. `ParameterService.cs`

- Добавлен метод `AddMissingCategories(Document, ElementId, ICollection<Category>)`.
- Метод получает существующую привязку, добавляет недостающие категории в `CategorySet` и вызывает `ReInsert`, сохраняя тип `InstanceBinding`.
- В `ValidateParameterCategories` при `TypeBinding` устанавливается `IsTypeBinding = true` вместо добавления служебной строки в список категорий.

### 5. `OrchestratorService.cs`

- После выбора `ADSK_Группирование` и перед созданием видов:
  - вызывается `AddMissingCategories` для автоматической привязки недостающих категорий внутри той же транзакции.

## Исправление бага: IsValid и отсутствующие категории

- Проблема: в `ValidateParameterCategories` строка `result.IsValid = result.AllCategoriesBound` делала результат невалидным при наличии непривязанных категорий. Из-за этого `MainWindow` показывал красное сообщение «Параметр не найден» вместо счётчика.
- Исправление: `IsValid` остаётся `true`, если сам параметр и его `InstanceBinding` корректны. Непривязанные категории учитываются только через `MissingCategories.Count`.
- Также сообщение о создании нового параметра перекрашено в оранжевый.
