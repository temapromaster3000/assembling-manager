# Смысловые иконки для модулей ленты

## Проблема

Все 6 кнопок ленты плагина используют одну общую иконку (`Icon16.png`/`Icon32.png`) — модули визуально не различаются.

## Цель

У каждого модуля — своя смысловая пара иконок (16×16 и 32×32, PNG 32bpp ARGB, прозрачный фон) в единой гамме: синий `#0078D4` + серый + белый (совпадает со стилем кнопки «Выполнить»).

## Концепты

| Кнопка (панель) | Пиктограмма | Ресурсы |
|---|---|---|
| Настройки | шестерёнка | `Settings16/32.png` |
| Сформировать виды (Сборки) | изометрический 3D-куб | `CreateViews16/32.png` |
| Переименовать виды (Сборки) | карандаш под 45° | `Rename16/32.png` |
| Разместить на листах (Листы) | лист с заголовком и рамкой вида внутри | `PlaceSheets16/32.png` |
| Сортировка листов (Листы) | строки + стрелки вверх/вниз (в 16 px — одна стрелка вниз) | `SortSheets16/32.png` |
| Проставить позиции (Оформление) | нумерованный список 1-2-3 + строки | `Positions16/32.png` |

## Реализация

1. **Новый `tools/make-icons.ps1`** — генератор иконок (PowerShell + System.Drawing). Все координаты в пространстве 32×32, для 16 px применяется масштаб с упрощениями (без цифр в чипах, одна стрелка сортировки). Скрипт также умеет сохранять контактный лист для визуальной проверки: `powershell -File tools\make-icons.ps1 -PreviewPath <файл>`. Запуск вручную при необходимости правки иконок — в сборку не встроен.
2. **`src/AssemblingManager.Revit/Resources/`** — 12 сгенерированных PNG; старые `Icon16.png`/`Icon32.png` удалены.
3. **`AssemblingManager.Revit.csproj`** — два явных `<EmbeddedResource>` заменены на wildcard `<EmbeddedResource Include="Resources\**\*.png" />` (новые файлы подхватываются автоматически).
4. **`App.cs`** — каждой из 6 кнопок заданы свои `LargeImage`/`Image` по именам манифест-ресурсов `AssemblingManager.Revit.Resources.<Имя>16/32.png`; метод `LoadEmbeddedImage` не менялся (при опечатке возвращает `null` — кнопка остаётся с текстом, плагин не падает).
5. Техническая деталь: в WPF-проекте PNG попадают и в манифест напрямую, и в `.g.resources`; проверка выполнялась перечислением манифест-ресурсов собранной DLL (`bin\<Config>\<RevitVersion>\AssemblingManager.dll`).

## Контрольный список ручной проверки

1. Собрать и развернуть плагин (`build-and-deploy.bat`), перезапустить Revit.
2. Убедиться: у каждой из 6 кнопок своя иконка (шестерёнка, куб, карандаш, лист, сортировка, нумерованный список).
3. Свернуть/развернуть панели ленты — мелкие 16 px иконки отображаются корректно.
4. Все кнопки запускают свои модули (иконки не «перепутаны» между кнопками).
5. Если какая-то иконка не нравится — правится форма в `tools/make-icons.ps1` и перегенерируется.
