# План: модуль «Разместить на листах» — новая логика (без конфликтов)

## Принцип
Модуль анализирует только карту фактического размещения видов на листах
(мастер-лист учитывается как обычный: виды, лежащие на нём, считаются размещёнными).
Имена листов, смешанные листы, продолжения «(начало)/(окончание)» и т.п.
не анализируются. Окна конфликтов нет: модуль только создаёт листы
и размещает на них виды, ещё не размещённые.

## Логика по объекту (группе видов одной сборки)
1. Все виды группы уже размещены на листах → пропуск (счётчик «полностью размещено»).
2. Ни один вид не размещён → обычный новый лист с именем сборки,
   номер = от максимума номера в выбранной группе листов (по формату мастера) + 1.
3. Часть видов размещена, часть нет → сигнальный лист
   `<ИмяСборки> (не размещенное)`, размещаются только неразмещённые виды —
   визуальный сигнал проектировщику (удалить виды или оформить лист).

## Номера листов
- Отсчёт от максимального номера в ВЫБРАННОЙ группе листов (где выбран мастер),
  ищущегося только среди номеров того же формата (одинаковый префикс), что у мастера.
- Если в группе только мастер — отсчёт от мастера +1 (как раньше).
- Ведущие нули сохраняются (`Т-01` → `Т-02…Т-09`); занятые номера
  (в модели: весь глобальный набор) пропускаются — берётся первый свободный.
- Если в номере мастера нет цифр в конце — схема `мастер-01`, от максимума группы.

## Предпросмотр перед созданием
- После нажатия «Разместить» (в окне выбора) модуль рассчитывает план
  (`BuildPlacementPlan`: карта размещений, списки листов и их номера) и показывает
  окно: «Будет создано листов: n (сигнальных: m). Полностью размещено групп: k».
- Список: номер — имя листа; сигнальные подсвечены мягким красным.
- «Разместить» — выполняет план; «Отмена» — ничего не создаётся.
- Если создавать нечего — окно с сообщением, выход без изменений.
- План один и тот же для превью и исполнения.

## Сортировка листов в дереве
- `NaturalStringComparer` (числовые сегменты сравниваются численно):
  `…01…09, 10, …, 36` вместо строкового `10 < 2 < 36 < 7`.
- Применяется в `BrowserGroupService.BuildSheetTree` (листы, папки)
  и `SheetService.GetSheets`.

## Чек-лист ручной проверки (агент не может запустить Revit)
1. Группа без размещённых видов → создан обычный лист, виды вокруг листа.
2. Часть видов размещена → сигнальный лист `Сборка (не размещенное)`
   только с неразмещёнными видами; существующие листы не тронуты.
3. Повторный запуск (виды уже размещены) → новых листов нет, «полностью размещено» = все группы.
4. Смешанные листы (виды 2+ сборок) и «(начало)/(окончание)» — не тронуты.
5. Номер нового листа = max номер в группе (по формату мастера) + 1
   (ведущие нули сохраняются; занятый — пропуск на следующий свободный).
6. Выделение в левом/правом дереве яркое (синее), не гаснет при переключении окон.
7. Ctrl+Z после модуля — всё откатывается одним шагом.
