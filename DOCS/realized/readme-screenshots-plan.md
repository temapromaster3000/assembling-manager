## Технические решения

- Путь к картинкам — `DOCS/images/...` с заглавными: в git папка называется `DOCS`, а Windows не различает регистр (на диске она видна как `docs`). GitHub регистр различает, поэтому в README нужен именно `DOCS/`.
- Картинки вставляются HTML-тегами, чтобы задать ширину (`875` для ленты, `606` для окна) и не растягивать PNG до 4K.
- Обе картинки отдаются в натуральном размере — без апскейла и размытия.
- Ссылки на изображения относительные: работают и на GitHub, и в локальном клоне, и в превью IDE.
- Alt-текст на русском: показывается, если картинка не загрузилась.
