# План: улучшение окна отчёта (ReportDialog)

## Цель
Привести окно «Результат» к общему стилю плагина и сделать отчёт читаемым.

## Изменения

### 1. Общие стили и кнопка
- Подключён общий словарь `Styles/Common.xaml` (путь с указанием сборки).
- Кнопка «OK» — стиль `PrimaryButton` (синяя скруглённая, как в остальных окнах). Enter/Esc закрывают окно как раньше (`IsDefault`/`IsCancel`).

### 2. Статистика таблицей вместо сплошного текста
- Жирный заголовок «Формирование видов завершено.»
- Сетка из двух колонок: слева метка, справа жирное значение, выровненное по правому краю:
  - «Создано видов» — если больше нуля;
  - «Заменено видов» — если больше нуля;
  - «Пропущено видов» — если больше нуля;
  - «Время работы» — всегда, формат `X,XX с` (как раньше).
- Строки добавляются из кода методом `AddStatistic(label, value)` — легко расширять новыми пунктами.
- `StringBuilder` удалён за ненадобностью.

### 3. Размеры окна
- Фиксированная ширина 340, высота по содержимому (`SizeToContent="Height"`), без изменения размера, отступы 20 px.

## Контрольный список ручной проверки (в Revit)
1. Собрать и развернуть плагин через `build-and-deploy.bat`.
2. Сформировать виды для сборки и дождаться окна «Результат»:
   - [ ] Окно шириной 340, аккуратные отступы 20 px.
   - [ ] Заголовок «Формирование видов завершено.» жирный.
   - [ ] Статистика выровнена: метки слева, жирные значения справа.
   - [ ] Нулевые пункты (например «Пропущено видов») не показываются.
   - [ ] Кнопка «OK» синяя, со скруглением; при наведении темнеет.
   - [ ] Enter и Esc закрывают окно.
