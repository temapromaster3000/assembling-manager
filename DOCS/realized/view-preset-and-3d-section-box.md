# План: пресет главного окна и отключение «Границ 3D вида»

## Статус

In progress.

## Цель

Два улучшения модуля «Сформировать виды»:

1. Пресет выбранных параметров главного окна сохраняется в проекте: после первого нажатия «Сформировать» окно при следующих запусках открывается с теми же настройками. Сохранение выполняется сразу при нажатии кнопки, до начала генерации (как в модуле «Оси трубопроводов»).
2. При создании 3D-видов не включается «Границы 3D вида» (Section Box). Раньше плагин сам задавал границы через `SetSectionBox`, из-за чего в видовом окне могла не отображаться часть элементов. Видимость управляется фильтрами, обрезка не нужна. У существующих 3D-видов границы гасятся при действии «Обновить».

## Поведение

### Пресет главного окна
- Хранится в `DataStorage` проекта через ExtensibleStorage — как пресеты остальных модулей (тэги, позиции, оси труб и соседние оси).
- Сохраняется при каждом нажатии «Сформировать» в главном окне, даже если затем пользователь отменит операцию в окне конфликтов.
- «Число непривязанных категорий» не сохраняется — это временное состояние окна, пересчитывается при каждом открытии.
- Если сохранённый шаблон вида / тип семейства / мастер-спецификация удалены из проекта, окно откатывается на первый пункт списка (существующая логика `SelectTemplateById` / `SelectTypeById`).

### 3D-виды
- Создание и дублирование: границы 3D-вида не задаются — галочка снята.
- Действие «Обновить»: если границы активны — гасятся (`IsSectionBoxActive = false`).
- Действие «Заменить»: новый вид создаётся без границ.
- Действие «Оставить»: вид не изменяется (границы сохраняются, если были).

## Изменения в коде

### 1. `Services/ViewPresetStorage.cs` (новый файл)
- Статический класс по образцу `TagPresetStorage`.
- Схема `AssemblingManagerViewPreset` с уникальным GUID (не совпадает с 5 существующими схемами плагина).
- Поля: `UseGrouping` + 7 флажков видов (bool), 8 идентификаторов шаблонов/типов/спецификации (int, 0 = «не выбрано»).
- `ReadOptions(Document)` → `ViewCreationOptions` или `null`, если пресета в проекте ещё нет.
- `SaveOptions(Document, ViewCreationOptions)` — транзакция «Сохранить пресет видов».

### 2. `Commands/CreateAssemblyViewsCommand.cs`
- Перед первым открытием окна: если `options == null` — прочитать `ViewPresetStorage.ReadOptions(document)`.
- Сразу после `options = window.Options` — `ViewPresetStorage.SaveOptions(document, options)`.

### 3. `Services/ViewService.cs`
- Метод `Apply3DViewGeometry` удалён; вместо него имя задаётся напрямую, `SetSectionBox` больше не вызывается.
- У `Create3DView`, `Duplicate3DView`, `Update3DViewGeometry` убран параметр `bbox` (больше не нужен).
- `Update3DViewGeometry`: вместо расширения границ — деактивация при активности, с разблокировкой/блокировкой вида как раньше.

### 4. `Services/OrchestratorService.cs`
- Обновлены лямбды создания/дублирования/обновления 3D-видов (вызовы без `bbox`).

## Совместимость
- Модуль «Оси трубопроводов» не затронут: прогоны лучей `ReferenceIntersector` используют целевые элементы самой сборки, а `IsSectionBoxActive` в нём используется только в диагностическом логе.
- Размещение на листах не зависит от границ: для 3D-видов размер вьюпорта считается от доли листа (`SheetService.EstimateViewportSize`).
