# Assembling Manager

C#-плагин для Autodesk Revit 2021–2025, автоматизирующий полный цикл выпуска документации по сборкам (`AssemblyInstance`): от создания видов и спецификаций до листов, позиций и марок.

Плагин работает на вкладке **Assembling Manager** ленты Revit (панели «Сборки», «Листы», «Оформление», «Настройки»).

## Возможности

### 📐 Сформировать виды

Основной модуль. По каждой сборке модели создаёт комплект видов: **план, четыре разреза (фронт, тыл, слева, справа) и 3D-вид**, плюс сборочные спецификации (дубликаты мастер-спецификации с фильтром по имени сборки).

Как это работает:

1. Видимые элементы сборки определяются по параметру `AssemblyParameter` (или существующему `ADSK_Группирование`) — на видах остаётся только «своё», посторонние элементы скрываются фильтрами.
2. Вложенные общие семейства обрабатываются рекурсивно.
3. Границы видов вычисляются по габариту элементов сборки (обрезка плана, рамки разрезов, разрезбокс 3D), 3D-виды автоматически запираются.
4. Применяются выбранные шаблоны видов (план / разрезы / 3D / спецификация).

Если виды уже существуют, открывается окно конфликтов с выбором действия для каждого вида:

- **Оставить как есть** — вид не трогается;
- **Обновить** — плагин только расширяет границы вида под текущий габарит сборки (для случаев, когда в сборку добавились элементы). Аннотации, теги и оформление проектировщика сохраняются, поскольку вид не пересоздаётся;
- **Заменить** — вид удаляется и создаётся заново по шаблону.

Спецификации при «Обновлении» не пересоздаются — их поля и форматирование сохраняются. Все операции выполняются в одной транзакции: при ошибке ничего не меняется.

### ✏️ Переименовать виды

Переименовали сборку вручную? Один клик находит все несоответствия и приводит их к текущему имени сборки: имена видов и спецификаций, значения параметра `AssemblyParameter` на элементах, фильтры и фильтры спецификаций. Перед применением показывает список переименований, после — отчёт.

### 📄 Разместить на листах

Выбираете лист-образец и группу видов — плагин копирует лист для каждого объекта группы и размещает на нём виды сборок (два режима раскладки: компактный и по сетке). Виды, которые не удалось разместить, попадают на сигнальный лист «(не размещенное)» — по нему видно, что вы забыли разместить или удалить.

### 🗂 Сортировка листов

Приводит листы выбранной группы к порядку по именам сборок:

- имена листов приводятся к именам сборок;
- перенумерация с естественным порядком чисел («Лист 2» раньше «Листа 10»);
- удаление пустых листов;
- опциональное удаление сигнальных листов «(не размещенное)» вместе с плагиновыми видами и спецификациями на них (посторонние виды сохраняются с предупреждением);
- отчёт с фактическими счётчиками и предупреждениями о занятых другими пользователями элементах.

### 🔢 Проставить позиции

- **Нумерация позиций** по строкам выбранных спецификаций: диапазон номеров, сортировка по имени сборки, пропуск строк по ключевым словам.
- **Марки позиций** на планах и разрезах с настраиваемыми смещениями и автоподбором свободных мест (пресеты маркировки сохраняются).
- **Режим «Только позиции»** — проставить номера без размещения марок.
- **Объединение спецификаций**: при сквозной нумерации нескольких спецификаций их куски подписываются именами сборок и соединяются в одну таблицу на листе.

### ⚙️ Настройки и обновления

Кнопка «Настройки» показывает текущую версию плагина, проверяет обновления на GitHub и показывает «что нового». Обновление скачивается и применяется автоматически после закрытия Revit.

## Работа в файл-хранилище

Плагин рассчитан на совместную работу в workshared-моделях:

- занятые другими пользователями элементы не срывают прогон: операции проверяют занятость, пропускают чужое и подробно отчитываются (кто держит элемент, что не удалено/не перенумеровано);
- фильтры видов переиспользуются, а не пересоздаются — виды, с которыми работают коллеги, не теряют настройки;
- всё, что не удалось сделать из-за занятости, видно в отчётах и в логе; детали — в файле лога в `%APPDATA%\Autodesk\Revit\Addins\AssemblingManager\Logs`.

## Установка

**Способ 1 — инсталлятор (рекомендуется):** скачайте `AssemblingManager-<версия>-setup.exe` со страницы [Releases](https://github.com/temapromaster3000/assembling-manager/releases), запустите — установщик сам найдёт установленные версии Revit (2021–2025) и зарегистрирует плагин.

**Способ 2 — zip вручную:** скачайте `AssemblingManager-R<XX>.zip` для вашей версии Revit и распакуйте содержимое в `%APPDATA%\Autodesk\Revit\Addins\<Год>\`, либо следуйте инструкции внутри архива.

**Способ 3 — из исходников:** см. раздел «Сборка» ниже и скрипт `build-and-deploy.bat`.

## Обновление из Revit

Откройте **Assembling Manager → Настройки → Проверить обновления**. Плагин сверится с последним GitHub-релизом, покажет «что нового» и предложит скачать установку; обновление применится после закрытия Revit.

## Требования

- Autodesk Revit 2021 / 2022 / 2023 / 2024 / 2025
- Windows 10/11 x64
- [.NET SDK 8.0](https://dotnet.microsoft.com/download) — только для сборки из исходников.

## Сборка

Плагин ссылается на API Revit через NuGet-пакеты `Nice3point.Revit.Api.*`, поэтому локально установленный Revit для сборки не требуется.

```powershell
dotnet build build\AssemblingManager.sln -c Debug.R21
```

Конфигурации: `Debug.R21` … `Debug.R25` (и соответствующие `Release.*`). Выходные файлы — в `bin\<Конфигурация>\<Год>\`.

Скрипт `build-and-deploy.bat` собирает все версии и устанавливает их в Revit (DLL в `%APPDATA%\AssemblingManager\<Год>\`, манифесты `.addin` в `%APPDATA%\Autodesk\Revit\Addins\<Год>\`). Установленные версии Revit, отсутствующие на машине, пропускаются.

Выпуск релиза: запустите `tools\release.bat` (нужны [GitHub CLI](https://cli.github.com/) с авторизацией и [Inno Setup 6](https://jrsoftware.org/isinfo.php)) — он соберёт все конфигурации, упакует zip-архивы и инсталлятор, опубликует GitHub Release по версии из `Version.txt`.

## Структура проекта

```
assembling-manager
├── src/
│   ├── AssemblingManager.Core/        # Общие модели, константы, утилиты
│   ├── AssemblingManager.Revit/       # Точка входа, команды, сервисы, UI
│   └── AssemblingManager.Updater/     # Консольный применитель обновлений
├── build/AssemblingManager.sln        # Решение Visual Studio
├── addins/                            # Манифесты .addin для каждой версии Revit
├── DOCS/                              # Планы фич (realized / in-progress / future)
├── tools/                             # Релизный конвейер и инсталлятор
├── build-and-deploy.bat               # Сборка и установка в Revit
└── Version.txt                        # Версия плагина (единый источник)
```

## Отладка

1. Запустите `build-and-deploy.bat`.
2. Запустите Revit и любую команду плагина с вкладки **Assembling Manager**.
3. В Visual Studio выберите **Debug → Attach to Process** и подключитесь к `Revit.exe`.

Лог работы плагина пишется в `%APPDATA%\Autodesk\Revit\Addins\AssemblingManager\Logs\`.

## Важно

- `RevitAPI.dll` и `RevitAPIUI.dll` не входят в репозиторий — приходят через NuGet.
- Для коммерческого использования замените `VendorId` и `VendorDescription` в `addins/20XX/AssemblingManager.addin`.
- `AddInId` в манифестах задан уникальным GUID. При конфликте с другим плагином замените его.
