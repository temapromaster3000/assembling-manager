# Assembling Manager 1.4.0

Новый модуль «Сортаменты труб» — редактор каталогов размеров труб с автоматическим переносом труб и обновлением Routing Preferences: больше не нужно править каждую трубу вручную.

## 📏 Сортаменты труб (новый модуль)

Модуль в группе **Трубы** показывает все каталоги размеров (`PipeSegment`) активного документа. Для выбранного каталога можно открыть отдельный диалог добавления нового номинального диаметра, изменить наружный диаметр и толщину стенки существующего размера или удалить неиспользуемый размер. Внутренний диаметр рассчитывается автоматически; номинальный диаметр в таблице только для чтения, размеры показываются в единицах проекта.

Как работает замена каталога:

- любые изменения не оставляют старый сегмент: сначала плагин копирует исходный сегмент с сохранением материала; если Revit при копировании дублирует материал, копирование откатывается и создаётся замена через API — с исходным материалом, Спецификацией/Типом и описанием;
- все трубы активного документа, использовавшие старый сегмент, переносятся на новый автоматически, Routing Preferences обновляются вместе с каталогом — новые трубы сразу получают его;
- после переноса старый сегмент удаляется, а новому возвращается исходное имя (при невозможности — свободный суффикс «Имя1», «Имя2» и далее);
- исходный материал никогда не создаётся, не дублируется и не удаляется; для сегментов без материала так и остаётся без материала;
- фитинги, изоляция и другие MEP-элементы не затрагиваются.

Детали поведения:

- DN, используемый трубами, удалить нельзя: строка подсвечивается красным, кнопка удаления блокируется;
- изменения нескольких сегментов накапливаются в черновиках при переключении и применяются одной операцией; «Отмена» не меняет модель;
- успешный отчёт содержит только общие количества: изменённых сегментов, добавленных, изменённых и удалённых размеров; подробности — в файле лога;
- при любой ошибке операция откатывается целиком, модель не остаётся наполовину изменённой.

## 📦 Установка

1. Скачайте `AssemblingManager-1.4.0-setup.exe` ниже.
2. Запустите — установщик сам найдёт ваши версии Revit (2021–2025) и зарегистрирует плагин.
3. Откройте Revit — вкладка **Assembling Manager** уже на ленте.

Если установлена версия 1.3.1 (или старее), окно «Настройки» предложит обновление — оно применится автоматически после закрытия Revit.

## ✅ Требования

- Autodesk Revit 2021 / 2022 / 2023 / 2024 / 2025
- Windows 10/11 x64
