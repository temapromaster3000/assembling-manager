# Assembling Manager 1.3.0

Новый модуль «Оси трубопроводов», запоминание настроек главного окна и исправление нумерации позиций.

## 🧵 Оси трубопроводов (новый модуль)

В дисциплине вида «Координация» Revit не показывает оси труб, а в MEP-дисциплинах все элементы теряют скрытие линий и просвечивают. Модуль решает это аннотационными линиями на планах и разрезах выбранных сборок — дисциплина вида не меняется:

- оси рисуются по всем видимым трубам вида и привязаны к выбранному **стилю линий** проекта (он же — метка линий плагина);
- **обрезка перекрытых участков**: труба за отводом, фитингом или стеной получает ось только на видимых кусках — проверка перекрытий лучами по собственному 3D-виду сборки (чекбокс «Пропускать перекрытые участки», по умолчанию включён; выключен — оси рисуются целиком);
- **«Нанести оси» / «Удалить оси»**: повторный запуск по тому же стилю обновляет оси без дублей; удаление трогает только линии выбранного стиля в видах выбранных сборок;
- многопроходная проверка по стадиям: перекрытие учитывает элементы любой стадии («Существующая» тоже перекрывает);
- сборки выбираются в окне с поиском, «Выбрать всё» и счётчиком; пресет (сборки, стиль, чекбокс) сохраняется в проекте;
- короткие проекции (стояки на планах, трубы вдоль взгляда на разрезах) пропускаются со счётчиком в отчёте.

## ⚙️ Сформировать виды — настройки запоминаются

- **Пресет главного окна хранится в проекте**: после первого нажатия «Сформировать» окно при следующих запусках открывается с тем же выбором видов, шаблонов, типов семейств и мастер-спецификации. Настройки — у каждого проекта свои; если сохранённый шаблон удалён, окно откатывается на первый пункт списка.
- **Границы 3D-вида больше не включаются**: раньше плагин сам задавал «Границы 3D вида» (Section Box), и из-за них часть элементов могла не отображаться. Теперь 3D-виды создаются без границ — видимость по-прежнему управляется фильтром. У существующих 3D-видов границы гасятся при действии «Обновить», «Заменить» создаёт вид сразу без них.

## 🔢 Проставить позиции — порядок как в Revit

Исправлена нумерация позиций: раньше порядок мог расходиться со строками спецификации там, где текст содержит числа («Труба о89» должна идти раньше «Труба о108», «Заглушка 80» — раньше «Заглушки 100», «M16x85» — раньше «M16x120»). Теперь:

- числа внутри текста сравниваются как числа (натуральная сортировка — как в Revit);
- числовые параметры сортировки сравниваются по значению, а не как текст;
- значения полей читаются по идентификатору параметра — исключена путаница одноимённых параметров у элементов и их типов;
- в логе видны сырые поля сортировки спецификации, итоговый порядок групп и соответствие «позиция → значения» — расхождения отслеживаются без догадок.

## 📦 Установка

1. Скачайте `AssemblingManager-1.3.0-setup.exe` ниже.
2. Запустите — установщик сам найдёт ваши версии Revit (2021–2025) и зарегистрирует плагин.
3. Откройте Revit — вкладка **Assembling Manager** уже на ленте.

Если плагин 1.2.0 (или старее) уже установлен, окно «Настройки» предложит обновление — оно применится автоматически после закрытия Revit.
