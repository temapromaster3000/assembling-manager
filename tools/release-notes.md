# Assembling Manager 1.0.0

Первый публичный релиз плагина **Assembling Manager** — набора инструментов для автоматической работы со сборками (`AssemblyInstance`) в Autodesk Revit 2021–2025.

Плагин закрывает полный цикл выпуска документации по сборкам: от создания видов до листов, спецификаций и позиций.

## 📐 Сформировать виды
- Для каждой сборки модели автоматически создаются: **план, два разреза и 3D-вид**.
- Видимые элементы определяются по параметру `AssemblyParameter` — на видах остаётся только «своё».
- Вложенные общие семейства обрабатываются рекурсивно.
- Посторонние элементы скрываются фильтрами по параметру.

## ✏️ Переименовать виды
- Переименовали сборку? Один клик — и все **виды, значения параметров и фильтры** приведены к новому имени.
- Плагин найдёт расхождения по всей модели и покажет отчёт перед применением.

## 📄 Разместить на листах
- Выберите объекты и лист-образец — плагин **скопирует лист для каждого объекта** и сам разложит на нём план, разрезы, 3D-вид и легенду.
- Умная работа с конфликтами: если лист уже существует, плагин предложит пропустить, заменить или дополнить его.
- Два режима раскладки видов на листе — компактный и по сетке.

## 🔢 Сортировка листов
- **Удаление пустых листов** в один клик.
- Имена листов приводятся к именам сборок.
- Перенумерация с естественным порядком чисел: «Лист 2» встанет раньше «Листа 10».

## 🏷️ Проставить позиции
- Автоматическая **нумерация сборок по строкам спецификаций**: диапазон номеров, сортировка по имени сборки, пропуск строк по ключевым словам.
- **Марки позиций на планах и разрезах** с настраиваемыми смещениями и автоподбором свободных мест.

## ⚙️ Настройки и обновления
- Версия плагина и **проверка обновлений прямо из Revit** — кнопка «Настройки» на вкладке плагина.
- Обновление скачивается и применяется автоматически после закрытия Revit.

## 📦 Установка
1. Скачайте `AssemblingManager-1.0.0-setup.exe` ниже.
2. Запустите — установщик сам найдёт ваши версии Revit (2021–2025) и зарегистрирует плагин.
3. Откройте Revit — вкладка **Assembling Manager** уже на ленте.

## ✅ Требования
- Autodesk Revit 2021 / 2022 / 2023 / 2024 / 2025
- Windows 10/11 x64
