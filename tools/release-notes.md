# Assembling Manager 1.1.0

Обновление «Сборок»: сохраняем оформление проектировщика и делаем работу в файл-хранилище безопаснее.

## 📐 Сформировать виды

- **Новое действие «Обновить»** в окне конфликтов. Если к сборке добавились новые элементы, существующие виды больше не нужно пересоздавать (и терять аннотации и оформление): плагин только расширяет границы вида — обрезку плана, рамки разрезов и разрезбокс 3D — чтобы новые элементы попали в кадр. Спецификации при «Обновлении» не пересоздаются — их поля и форматирование сохраняются.
- Выбор действия для каждого вида: **Оставить как есть / Обновить / Заменить**, плюс кнопки «Обновить всё» и «Заменить всё».
- **Фильтры больше не слетают у коллег**: фильтры переиспользуются вместо пересоздания, поэтому виды, занятые другими пользователями в файл-хранилище, сохраняют свои фильтры. После прогона плагин сам проверяет наличие фильтров на видах и пишет предупреждения (вид без фильтра, шаблон вида блокирует фильтры) в лог.
- Подробный лог по каждой сборке: создание/переиспользование фильтров, назначения на виды, итоги верификации.

## 🗂 Сортировка листов

- **Новая галочка «Удалить сигнальные листы „(не размещенное)"»**: листы-подсказки удаляются вместе с плагиновыми видами и сборочными спецификациями на них. Посторонние виды, добавленные вручную, сохраняются и попадают в отчёт.
- Устойчивость к занятым элементам в файл-хранилище: перед удалением и перенумерацией плагин проверяет занятость, в отчёте — честные счётчики, «владельцы» занятых элементов и статус целостности нумерации («сбилась / не сбилась»).
- Многосборочные листы упорядочиваются по минимальному коду сборки.

## 🔢 Проставить позиции

- **Режим «Только позиции»**: проставить номера позиций по спецификациям без размещения марок на видах.
- **Объединение спецификаций с подписями**: при «сквозной нумерации» каждый кусок таблицы подписывается именем своей сборки в столбце «Наименование», у первого куска показывается название — куски соединяются в одну таблицу без ручных подписей.

## 🎨 Лента

- У каждой кнопки плагина — своя иконка: модули проще различать на вкладке.

## 📦 Установка

1. Скачайте `AssemblingManager-1.1.0-setup.exe` ниже.
2. Запустите — установщик сам найдёт ваши версии Revit (2021–2025) и зарегистрирует плагин.
3. Откройте Revit — вкладка **Assembling Manager** уже на ленте.

Если плагин 1.0.0 уже установлен, окно «Настройки» предложит обновление — оно применится автоматически после закрытия Revit.

## ✅ Требования

- Autodesk Revit 2021 / 2022 / 2023 / 2024 / 2025
- Windows 10/11 x64
