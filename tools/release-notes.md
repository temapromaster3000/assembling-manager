# Assembling Manager 1.5.0

Новый модуль «Проверка отметок» — быстрый контроль комплектов листов: плагин находит листы, ни на одном виде которых нет высотной отметки.

## ✅ Проверка отметок (новый модуль)

Модуль в группе **Оформление**:

- выбираете комплект листов — группу из дерева диспетчера проекта (как в «Сортировке листов»);
- нажимаете «Проверить» — плагин проходит по всем размещённым на листах видам;
- лист считается принятым, если высотная отметка есть хотя бы на одном его виде;
- в таблицу попадают листы без отметок, а также листы без размещённых видов;
- в таблице: номер листа, имя и количество видов на листе;
- ПКМ по строке → **«Перейти к листу»**: лист открывается в Revit, окно проверки остаётся открытым — можно продолжать работать с моделью;
- учитываются зависимые виды (dependent views);
- модуль только читает модель и безопасен в файл-хранилище.

## 🛠 Сборка

`build-and-deploy.bat` и `tools/release.ps1` теперь сами очищают служебные переменные расширения VS Code C# Dev Kit — сборка больше не падает при запуске из встроенного терминала.

## 📦 Установка

1. Скачайте `AssemblingManager-1.5.0-setup.exe` ниже.
2. Запустите — установщик сам найдёт ваши версии Revit (2021–2025) и зарегистрирует плагин.
3. Откройте Revit — вкладка **Assembling Manager** уже на ленте.

Если установлена версия 1.4.0 (или старее), окно «Настройки» предложит обновление — оно применится автоматически после закрытия Revit.

## ✅ Требования

- Autodesk Revit 2021 / 2022 / 2023 / 2024 / 2025
- Windows 10/11 x64
